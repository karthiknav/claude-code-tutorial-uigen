# Database Rules

- Use the Prisma singleton from `src/lib/prisma.ts`. Never call `new PrismaClient()` elsewhere.
- Do not edit files in `src/generated/prisma/` — they are auto-generated by `prisma generate`.
- Schema changes require a migration: `npx prisma migrate dev --name <description>`. Never edit `dev.db` directly.
- Do not run `npm audit fix` — dependencies are pinned to known-compatible versions and `audit fix` can break the app.
- `Project.messages` and `Project.data` are `String` columns storing JSON. Always serialize with `JSON.stringify()` before writing.
- Cascade deletes are configured on `Project → User` (`onDelete: Cascade`). Deleting a user removes all their projects.
- `userId` on `Project` is optional to support anonymous projects. Queries scoped to a user must filter by both `id` and `userId` to prevent unauthorized access.
